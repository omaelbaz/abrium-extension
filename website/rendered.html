Add to Chrome
Chrome extension · v0.1.0

Never lose a Claude Artifact again.

Abrium quietly catalogs every artifact you generate on claude.ai — code, documents, HTML, SVG — and keeps them searchable on your own machine. No account, no cloud, no tracking.

Add to Chrome View on GitHub
Free forever Open source Local-only No tracking

Auto-capture

Every artifact you open in a conversation is saved the moment it renders — including each revision, so earlier versions stay recoverable.

Gallery & search

A side panel that lists everything by type, conversation and date. Full-text search reaches into the artifact body, not just the title.

Batch export

Select any number of artifacts and download them as a folder-structured ZIP, with correct file extensions per type.

Five languages, real RTL

English, Arabic, French, Spanish and Portuguese. Arabic mirrors the entire layout — navigation, icons and reading order.

How it works

Three steps, then it disappears into the background.

1 Install and pin Add Abrium from the Chrome Web Store and pin it to the toolbar. No sign-up screen — there is no account.
2 Work as usual Keep using claude.ai. When an artifact appears in Code view, Abrium files it away with its title, type and source conversation.
3 Find it later Open the side panel, search or filter, then preview, copy, pin or export what you need.
